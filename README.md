# Ahorrapp — Política de Privacidad y eliminación de cuenta

Archivos:
- index.html: Política de Privacidad
- eliminar-cuenta.html: Recurso web para solicitar eliminación de cuenta

## Publicación
Estos archivos son estáticos y pueden publicarse en GitHub Pages, Netlify, Cloudflare Pages o un hosting equivalente.

Cuando el sitio esté publicado:
1. Usa la URL de `index.html` como Privacy Policy URL en Google Play Console.
2. Usa la URL de `eliminar-cuenta.html` como web resource de eliminación de cuenta.
3. La página de eliminación utiliza el correo bavilesl@outlook.com para recibir solicitudes, tal como permite la política de Google Play.

Antes de publicar:
- Confirma que el nombre del responsable sea exactamente el que aparecerá en Google Play.
- Confirma que el correo de privacidad sea correcto.
- No conviertas estas páginas en PDF para Play Console; deben permanecer accesibles como páginas web públicas.
